# AI로 비교안을 만들고 사람이 채택하는 제작 방식

## 역할

본인은 만들 경험과 범위를 정하고 직접 플레이한 뒤 방향을 고릅니다. 코드·검사·임시 리소스는 AI와 협업해 제작했습니다. 게임 코드 전체를 직접 손으로 작성한 프로젝트로 설명하지 않습니다.

Windows에서 Codex·Claude Code·Cursor 등을 사용했으며, 긴 작업의 구조화·실행·검토 조율에 가재코드(GJC)·OMO를 활용했습니다. 저장소에 공개한 것은 게임 코드와 기획 판단이며 외부 AI 도구의 소유권·개발 기여를 주장하지 않습니다.

## 반복 순서

1. 확인할 게임 경험 하나와 유지할 규칙을 적습니다.
2. 관련 파일, 재현 순서와 기대 결과를 AI에 제공합니다.
3. 계획과 작업 범위를 검토하고 독립적인 작업만 나누어 진행합니다.
4. 규칙·화면·저장 등의 변경을 통합하고 검사 근거를 대조합니다.
5. 실제 플레이와 시각 확인으로 채택하거나 반려합니다.
6. 실패 로그·기대 동작·다음 수정 이유를 남깁니다.

## 예시: 방송 준비 상태 분리

이 지시문은 과거 채팅 인용이 아니라 재현용 요약입니다.

> 영구 능력은 유지하고 방송 한 편의 준비 상태를 분리한다. 중간 방침은 한 번만 적용한다. 새로고침 후에도 선택과 난수가 유지되며 보상이 중복되지 않아야 한다. 적자에도 무료 선택으로 진행할 수 있게 한다. 규칙과 화면 변경을 연결하고 실행 근거를 남긴다.
