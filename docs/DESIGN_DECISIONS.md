# 비교하고 플레이한 뒤 바꾼 것

이 문서는 로컬 기획 기록의 결정과 구현 범위를 공개용으로 정리한 것입니다. 실험 기간은 2026년 9-10월이며 공개 저장소 생성일과 구분합니다.

## 1. 먼저 입력 방식을 비교한다

처음 확인할 것은 일정 선택과 결과 확인을 반복하는 작은 육성 사이클이었습니다. 행동 칸, 비율 배분, 운영 방침의 세 입력 방식을 같은 규칙과 시작 조건으로 비교했습니다.

직접 플레이한 뒤 비율 배분을 제외했습니다. 행동 네 칸의 직접 선택은 남기고 운영 방침은 칸을 한 번에 채우는 프리셋으로 결합했습니다. 당시 C 방식의 결과가 좋았어도 숙련 효과인지 분리하지 못했기 때문에 성능이나 선호의 정량 결과로 제시하지 않습니다.

## 2. 40분기로 늘렸을 때 드러난 반복감

10분기 구간에 비해 40분기에서는 반복이 크게 느껴졌습니다. 미니게임과 후일담이 늘어도 다음 계획을 바꾸는 이유가 충분히 늘어나는 것은 아니었습니다. 기능 추가 개수와 자동 검사 통과를 재미 개선의 근거로 삼지 않았습니다.

그래서 다음 실험의 질문을 ‘이번에 어떤 방송을 만들었는지 기억하고, 그 결과 때문에 다음 계획을 바꾸는가’로 좁혔습니다.

## 3. 영구 능력과 방송 한 편을 나눈다

방송감·게임·노래 같은 영구 능력과 이번 방송만의 실력 준비·볼거리·편안함·미해결 문제를 분리했습니다. 기여가 누적되고 중간에 한 번 방침을 고릅니다.

| 선택 | 얻는 것과 비용 | 방송에서 확인할 차이 |
| --- | --- | --- |
| 한 번 더 맞춰 보자 | 실력 준비 +11, 문제 -1, 4만원, 건강 -3 | 안정성과 실력 평가에 도움 |
| 실수도 살릴 장면을 만들자 | 볼거리 +11, 편안함 -2, 4만원 | 생방송에서 애드리브 1회 |
| 부담을 덜고 정리하자 | 편안함 +10, 문제 -2, 실력 준비 -3, 건강 +3 | 컨디션과 편안함에 도움 |
| 현재 계획대로 맡긴다 | 각 강점 +2, 문제 -1, 추가 비용 없음 | 추가 수동 선택 없이 진행 |

수치는 이 프로토타입의 실험 값입니다. 특정 전략이나 성공을 보장하지 않습니다.

## 4. 지난 방송 편집과 이번 방송 준비의 선택

이전 두 분기의 방송 중 편집 가능한 방송을 골라, 이번 볼거리 기여 한 번을 양보하고 후속 반응을 돕게 했습니다. 방송당 한 번만 편집하며 원래 후속 팬·수입 한도를 늘리지 않습니다.

## 5. 채택 기준과 남은 질문

- 무엇을 준비하는지 설명할 수 있는가?
- 준비한 것이 생방송에서 쓰였다고 느끼는가?
- 결과를 본 뒤 다음 계획을 바꾸거나 유지할 이유가 있는가?
- 선택이 매번 같아지거나 제작 과정이 기다림으로 느껴지지는 않는가?

현재 코드는 이 질문을 시험할 실행 환경입니다. 외부 플레이어의 장기 재미 개선이나 출시 시장성을 입증한 자료는 아닙니다. 이번 공개를 통해 실제 플레이로 확인할 수 있게 했습니다.
